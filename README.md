# Clarity — NUET Critical Thinking

English-language static learning site. Main sections: Logical reasoning (six lessons) and Text questions (seven lessons). Each Text questions lesson contains theory, a worked example and one multiple-choice exercise with instant feedback and explanation. The seven-question, seven-minute practice mock reuses those exercises. All materials are original, not official exam questions.

Run from this directory with `python3 -m http.server 8000`, then open the served site. No build, dependencies or API keys are needed. Progress is stored in this browser. Existing topic progress and mock history are retained; retired topic results are excluded from current practice statistics.

The dashboard clock counts down to 1 February 2027 at 00:00 UTC+5 and stops at zero. This is a preparation target, not a verified official exam date. Practice progress covers all 13 topics; the mock remains focused on the seven Text questions topics.
